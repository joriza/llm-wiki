- **Nota**: un «agente de código» ejecuta comandos, edita archivos y actúa sobre el sistema — el mismo rasgo que el caso Antigravity convirtió en riesgo; la autonomía y su control son el eje de la página.

## El concepto

Herramientas donde un LLM **actúa** sobre un proyecto (escribir código, correr comandos, editar archivos) siguiendo instrucciones en lenguaje natural, en lugar de solo sugerir texto. El corpus cubre la gama completa: extensiones de editor (Kilo Code), agentes de terminal (Claude Code, OpenCode, Pi), marcos de especificación (OpenSpec) y agentes de producto no-código (Antigravity).

## Arquetipos consolidados por las fuentes

1. **Extensión + modelo económico (Kilo Code + GLM 4.6)** — Kilo Code (VS Code, open source) con modos Architect/Code/Ask/Debug/Orchestrator; GLM 4.6 de Z.ai por 3 USD/mes; demo: API REST Laravel 12 completa y probada en 12 minutos «sin ningún error», con dos correcciones conversacionales del humano (tabla existente, rutas no registradas). Contraste: GPT-5 Codex CLI «no ejecuta nunca comandos» (12/57).
2. **El agente como director que orquesta (Claude Code + Remotion)** — un **skill** («receta que le enseña a Claude Code a hacer una tarea completa») genera vídeos estilo Vox: Claude no dibuja, orquesta ElevenLabs, Kie AI y Apify; el modelo importa («entre mejor el modelo, mejor queda tu vídeo» — Opus) y la primera versión nunca es la final (37/57).
3. **Vídeo programático con OpenCode** — prompt único → proyecto Remotion completo; reparto agente/humano: la IA construye, el humano corrige detalles finos (avatar PNG, dirección de animación, codec VP9 para transparencia) (38/57).
4. **El minimalista extensible (Pi)** — en contra del «todo preinstalado»: multi-proveedor por diseño, steering vs. cola (Alt+Enter), contexto bajo demanda (`#` vs `!!`), árbol de sesiones (`/tree`), skills bajo demanda y **extensiones TypeScript** con marketplace — «como Vim, en el lado de los agentes»; OpenClaw lo usa por debajo (26/57).
5. **Desarrollo dirigido por especificaciones (OpenSpec)** — antes de dejar actuar al agente: propuesta → viabilidad → implementación → **archivado para liberar contexto**; agnóstico del agente (Claude Code, Windsurf, Cursor, OpenCode, Kilo Code, Codex, Copilot) y admite proyectos ya iniciados (27/57).
6. **Interfaces unificadas de agentes** — AnythingLLM y OpenHands unifican Claude Code/Codex/Gemini CLI con chats, automatizaciones programadas y MCP; Paper Click y Gstack organizan agentes «como una empresa» (jerarquía, roles, costes, gobernanza) (34/57).
7. **Infraestructura 24/7 para agentes** — Herdr: multiplexor de terminal con persistencia (la sesión reaparece al reabrir), server en segundo plano, notificaciones cuando un agente termina o queda bloqueado y conexión remota (`--remote`); tesis del **mini PC siempre encendido** como arnés doméstico (54/57). Dotfiles + symlink para que skills y configuración de agentes (`.claude`, `.codex`, `.config/opencode`) sean un activo portable entre máquinas, con la carpeta `.agents` como formato compartido emergente (47/57). VPS con Docker para mantener agentes y herramientas corriendo sin el PC local (Odysseus, VoiceBox, FreeLLMAPI) (34/57, 42/57, 55/57).
8. **Orquestadores y ecosistemas completos** — tour de repos: OmniRouter (gateway de ~350 proveedores que salta de cuenta gratis automáticamente), Herdr/Orca (ADE en terminal y escritorio), un «VS Code para agentes» con worktrees, AnyDoc, skills de Matt Pocock (GrillMe) — hipótesis: los harnesses se multiplican porque la IA genera código y ya no hay barrera para construirlos (50/57). Gentle AI: ecosistema open source «opinado» sobre 16+ agentes con ODD como flujo por defecto, presupuesto de ~400 líneas por slice, RDD (review con lentes por severidad) y PRs encadenados (51/57, 52/57).
9. **Computer use textual (Agent Desktop)** — puente gratuito que da a Claude Code u otro agente control preciso de ratón y teclado: **traduce la interfaz visual a texto** en vez de interpretar capturas por visión — sabe dónde está cada campo; demo con un ERP de 2003 sin ninguna conectividad (57/57). Complemento del computer use por visión del ChatGPT de escritorio (voz + tareas programadas + plugins; el SO como capa secundaria) (45/57).
10. **La economía del agente** — FreeLLMAPI unifica solo modelos gratuitos de proveedores conectados con modos auto/fusión/enrutamiento y mapeo tipo Anthropic (Opus→potente, Sonnet→GLM, Haiku→ligero) (55/57); catálogo de APIs gratuitas de larga duración (NVIDIA, OpenRouter, agentrouter.org) (56/57); y los 11 trucos de ahorro de tokens: los modelos no tienen memoria y el **input reutilizado** es la mayoría del consumo — editar en vez de discutir, ventana nueva por tarea, handoff por fichero, MCP on-demand (verificar) frente a skills (que siempre pesan), prompt caching y compactación controlada (49/57).

## Seguridad de agentes: el contrapeso del corpus

- **El caso Antigravity**: un agente que «malinterpretó la orden de limpiar caché» ejecutó un borrado silencioso de una unidad completa, sin confirmación ni recuperación realista — «fallos de diseño en las salvaguardas de seguridad» y el debate sobre permisos y autonomía (15/57).
- **El protocolo resultante**: backups siempre; permisos mínimos; nunca producción — réplica local destructible, verificación humana de los scripts del agente (las primeras iteraciones daban falsos positivos), y desconfianza de fondo: «no puedes confiar ciegamente en un sistema que es un LLM» (15/57).
- **La supply chain de skills**: Skill Spector (Nvidia) inspecciona skills antes de instalarlas — «>26 % podrían contener vulnerabilidades» (prompt injection, jailbreaks) (34/57); el marketplace de Herdr repite la advertencia: ~1123 plugins, «revisa el código antes de instalar» (54/57).
- **Prompt injection como riesgo no resuelto**: en Clawdbot (asistente personal open source con memoria persistente en archivos) un documento recibido por correo con instrucciones invisibles puede exfiltrar contraseñas, sesiones y memoria — «las ventanas de contexto son vectores de ataque» (22/57).
- **El ratón y el teclado cedidos**: Agent Desktop implica permisos de accesibilidad y grabación de pantalla; el autor toca el ratón en ningún momento de la demo — la autonomía llega hasta el SO (57/57).
- Desde el marco crítico: el filtrado de Claude Code revela que los agentes punteros son en realidad **sistemas neurosimbólicos** (≈500.000 líneas de código simbólico + ~50 herramientas junto a la red neuronal) — «ahora todos lo hacen, pero nadie quiere admitirlo» (entrevista a Gary Marcus, corpus previo).

## Patrón transversal: el humano supervisa

En todas las fuentes el agente ejecuta, pero el humano mantiene el control del plan: correcciones conversacionales (12/57), priorización de tareas en OpenSpec (27/57), ajustes finos post-generación (38/57) y revisión visual antes de tocar producción (15/57). El dato que rige la adopción no es la inteligencia del modelo sino el **coste por resultado** (3 USD/mes vs. Claude Pro; modelos gratuitos por OpenRouter).

## El contexto como método: del prompt al criterio comprobable

Dos fuentes del cierre del lote generalizan el patrón más allá del código. La clase de La Hora Maker resume 2026 en **context engineering**: elegir qué entra en la ventana (memoria, instrucciones, skills, MCP, wiki interna) y **cerrar el bucle de feedback humano** (capturas de pantalla, reproducir errores) — los LLM no ven que se equivocan si nadie se lo hace llegar (29/57). Xavier Mitjana lo lleva al usuario final: el prompt es «la parte menos importante»; los niveles son encargo con contexto persistente (Projects/Gems) y criterio comprobable que la IA audita sola — «la versión no programador del spec-driven development» (53/57). SpecJudge cierra el círculo: leer las specs y recomendar **el modelo más pequeño que dé el rendimiento** antes de gastar un token (44/57).
