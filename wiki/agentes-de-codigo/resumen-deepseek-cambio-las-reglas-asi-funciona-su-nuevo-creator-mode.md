2. **Instalación y proveedor personalizado** [01:03-03:28]: instalación desde la aplicación de escritorio (también posible por línea de comandos). Recurso de la plataforma open source: trabajar con cualquier proveedor y modelo, a diferencia de Claude Code o Codex, que «solamente nos dejan trabajar con sus modelos». Configuración completa de un proveedor custom (panel → añadir model provider): API Key generada en el proveedor «Command Code» [ASR — proveedor no identificado, verificar], base URL de su documentación (api.commandcode.ai [ASR]), protocolo OpenAI Chat Completions y elección del modelo DeepSeek 4.1 Flash [ASR — verificar versión].

Formulación del canal: «estamos usando IA para ampliar las capacidades de la propia herramienta de IA». Reconoce que otros agentes también pueden desarrollar plugins — la novedad es que este modo está específicamente diseñado para facilitarlo dentro del arnés.
