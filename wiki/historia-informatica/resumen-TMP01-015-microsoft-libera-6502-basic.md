# TMP01-015 — Microsoft libera 6502 BASIC, que ahora es de código abierto

- **Fuente**: [Artículo web — Hipertextual](https://hipertextual.com/software/microsoft-libera-6502-basic-codigo-abierto/), ~11/2026.
- **Dominio**: `historia-informatica/` — historia del software y su conservación por apertura (hilo de los hitos de Microsoft).

## El hecho

Casi 50 años después de su debut, Microsoft liberó **Microsoft BASIC Versión 1.1 para el microprocesador 6502** (creado en 1976) como **código abierto**, en un repositorio oficial de GitHub — por primera vez completo y oficial, tras décadas de fragmentos y copias no oficiales circulando.

## Contexto histórico

- 1975: Gates y Allen lanzan el intérprete BASIC para el 8080 de Intel — el **primer producto de Microsoft** como empresa.
- 6502 BASIC (1976) fue un port para la CPU **6502 de MOS Technology**, uno de los chips más usados de las micros y consolas de fines de los 70 y los 80.
- **Commodore** lo licenció primero, en 1977, por **25.000 dólares** — llevó el BASIC a las PET, VIC-20 y Commodore 64.
- El port sirvió de base a **Applesoft BASIC**, intérprete de la Apple II en reemplazo del Integer BASIC de Wozniak.
- El 6502 también vivió en Atari 2600, Atari 800XL y NES — razón del interés sostenido en el código.

## Para qué sirve hoy

La apertura facilita revivir hardware antiguo: con **FPGA** se replican los equipos originales en hardware moderno con retrocompatibilidad real (mandos, cartuchos), algo imposible para un mero emulador. El intérprete incluye implementación completa del lenguaje: punto flotante, funciones matemáticas, E/S.
