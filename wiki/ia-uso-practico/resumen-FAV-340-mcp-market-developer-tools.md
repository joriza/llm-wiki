# FAV-340 — MCP Market: directorio de servidores MCP (categoría developer-tools)

- **Bookmark**: `https://mcpmarket.com/es/search?category_slug=developer-tools` (fuente web, favoritos Chrome — z-tmp/MCP)
- **Fecha de ingesta**: 2026-11-15
- **Dominio**: `ia-uso-practico/`

## Qué es

**MCP Market**, un directorio/mercado de servidores **MCP** (Model Context Protocol), filtrado a la categoría **developer-tools**. Sirve para descubrir servidores MCP que dan capacidades de herramientas de desarrollo a los agentes de IA.

## Qué se encuentra en la categoría

Listado de servidores de herramientas para desarrolladores, entre los visibles: **ChromeDevTools** (control del navegador DevTools), **Playwright** (Microsoft, automatización de navegador), **GitHub** (API de GitHub), **DayuanJiang**, **DeusData**, **Fission-AI**, **ahujasid**, **assafelovic**, **eyaltoledano**, **getzep**, **mindsdb**, **mksglu**, **morluto**, **obra**, **oraios**, **pascalorg**, **penpot** (diseño), **ruvnet**, **topoteretes**, **trycua**. La interfaz está disponible en español (`/es/`) y soporta búsqueda por categoría.

## Contexto

Dirección complementaria al repositorio oficial de servidores ([[resumen-FAV-343-servidor-mcp-fetch]]): el directorio es el descubrimiento, el repo oficial la referencia de implementación. Útil para explorar qué herramientas MCP existen antes de instalarlas en el propio flujo de trabajo con agentes.
