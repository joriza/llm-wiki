# Faker

- **Tipo**: página de entidad (herramienta).
- **Dominio**: `python-practico/`.
- **Actualizado**: 2026-11-11 (fuente 5/7 del lote python-practico).
- **Fuentes**: [[resumen-estas-5-librerias-de-python-parecen-demasiado-poderosas]].

**Faker** es el generador Python de **datos de prueba realistas**: no lorem ipsum ni «usuario de prueba 1», sino nombres, direcciones, teléfonos, correos, puestos de trabajo, tarjetas de crédito y empresas con apariencia real — miles de registros en menos de un segundo.

Casos de uso de la fuente:

- Probar un formulario de registro sin usar tu propio correo 50 veces.
- Poblar una base de datos con 10.000 clientes verosímiles antes de tener clientes reales.
- Armar una demo para inversores sin tablas de `test.com` — «la diferencia entre una demo de proyecto escolar y una que parece en producción».

Extras: **proveedores** específicos de tipos de datos (patentes, códigos de vehículos, cuentas bancarias, ubicaciones geográficas, y más).
