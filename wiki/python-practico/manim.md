# Manim

- **Tipo**: página de entidad (herramienta).
- **Dominio**: `python-practico/`.
- **Actualizado**: 2026-11-11 (fuente 5/7 del lote python-practico).
- **Fuentes**: [[resumen-estas-5-librerias-de-python-parecen-demasiado-poderosas]].

**Manim** (*Mathematical Animation Engine*) es la librería open source que genera **animaciones matemáticas** con código Python: ecuaciones que se transforman paso a paso, diagramas de sistemas que se construyen solos, redes neuronales armándose capa por capa.

Historia: la creó **Grant Sanderson**, el autor del canal 3Blue1Brown, porque no existía nada que animara la matemática como él quería — y después la liberó para que otros tuvieran «su superpoder». Usuarios típicos: estudiantes explicando tesis, profesores creando visualizaciones de clase, youtubers con acabado de motion graphics.

Advertencia de la fuente: **no es arrastrar-y-soltar** — las formas, transformaciones y tiempos se definen con código Python real, con curva de aprendizaje genuina. Es el extremo «educación/explicación» del bloque visualización del [[mapa-del-ecosistema-python]].
