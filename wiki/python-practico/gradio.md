# Gradio

- **Tipo**: página de entidad (herramienta).
- **Dominio**: `python-practico/`.
- **Actualizado**: 2026-11-11 (fuente 5/7 del lote python-practico).
- **Fuentes**: [[resumen-estas-5-librerias-de-python-parecen-demasiado-poderosas]].

**Gradio** es la librería open source que crea **demos web de modelos de machine learning en minutos**: envolvés una función Python en una interfaz declarando entrada y salida (ej. imagen → etiqueta), la lanzás, y el modelo queda con UI en el navegador que otros pueden usar de verdad — compartida por **un simple link**, sin registro, sin instalaciones ni `pip install` del lado del usuario.

Alcance: sirve para casi cualquier función Python que quieras mostrar — chatbots, reconocimiento de voz, generadores de imágenes, recomendadores, analizadores de documentos.

Peso en el ecosistema: **Hugging Face la adoptó como puerta de entrada a todo su ecosistema** — «la mitad de las demos de IA con botón “Pruébalo tú mismo” corren en silencio con Gradio». Es la alternativa de demo exprés frente a construir frontend propio; complementa a [[fastapi]] (API para sistemas en producción vs demo interactiva para mostrar).
