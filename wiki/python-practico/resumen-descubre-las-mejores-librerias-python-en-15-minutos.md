## Contenido por áreas

- **Librería estándar**: `os`/`shutil` (archivos y directorios), `collections` (`deque`, `Counter`), `itertools`, `datetime`, `re` (patrones de texto), `json` (serialización estándar de facto), `socket` (red).
- **Datos y ciencia**: el trío **NumPy** (arrays C, base de todo), **pandas** («navaja suiza» del análisis) y **Matplotlib** (visualización); SciPy como extensión científica.
- **Machine learning**: **scikit-learn** (ASR: «Sakit Learn») como punto de partida con API unificada de clasificación/regresión/clustering; **Statsmodels** para modelado estadístico estilo R.
- **Web**: **Django** (alto nivel, «batteries included»), **Flask** (microframework minimalista) y **FastAPI** (moderno, alto rendimiento, tipado); **BeautifulSoup** y Scrapy para scraping.
- **Automatización**: `subprocess`, `selenium` (navegadores), `requests` (HTTP), `openpyxl` (Excel), `python-docx`, `PyPDF2`.
- **IA**: **TensorFlow** y **PyTorch** (contraste flexibilidad investigación vs producción), **Keras** como API de alto nivel, **NLTK** para PLN académico.
- **GUI**: **Tkinter** (estándar), PyQt/PySide (escritorio completo).
- **Imágenes y visión**: **Pillow** (fork moderno de PIL), **OpenCV**.
- **Testing y calidad**: `unittest`, **pytest** (preferido por sintaxis), **tox** (múltiples entornos), **coverage.py** (cobertura).
