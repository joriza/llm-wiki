## Qué trata

Tutorial de instalación y primera impresión de **Deepin 25.2** (distribución Linux china de estética cuidada, apodada «Windows chino») como alternativa para PCs que funcionan pero no cumplen los requisitos de Windows 11 (TPM 2.0, lista de CPU aprobadas):

- **Instalación paso a paso**: ISO de 6,5 GB (x86_64) desde la web oficial → USB booteable con Rufus (modo dual Alt+E para compatibilidad) → arranque por BIOS/boot menú → modo live para probar sin instalar → instalador con disco completo, partición específica o junto a Windows; detección automática del driver Nvidia. Primer inicio: cuenta, teclado, zona horaria.
- **La experiencia**: interfaz deliberadamente familiar para migrantes de Windows 11 (barra inferior con dock, bandeja y controles rápidos, menú limpio, transparencias/animaciones/esquinas redondeadas), explorador con pestañas y partición de datos separada, centro de control categorizado — «una de las partes mejor logradas: incluso si nunca usaste Linux encontrás todo». Tienda de aplicaciones gráfica (sin terminal — el punto que más intimida a novatos) y ecosistema propio desde el primer arranque (navegador, multimedia, LibreOffice).
- **IA integrada**: asistente de Deepin para resumir, traducir, trabajar con texto y buscar archivos por lenguaje natural, con **modelos locales** en determinados escenarios para uso sin conexión.
- **Límite honesto**: no convierte cualquier PC antigua en rápida — la documentación recomienda 8 GB RAM, 64 GB de disco y SSD para fluidez; la ventaja real es no necesitar TPM 2.0 ni CPU aprobada por Microsoft.
