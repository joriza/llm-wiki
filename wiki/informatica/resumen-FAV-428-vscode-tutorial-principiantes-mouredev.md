## Qué es VS Code (visión de MoureDev)

Panorama en ~10 minutos, menos práctico y más conceptual que el curso de HolaMundo (FAV-426):

1. **Contexto**: editor más utilizado del mundo (~74% de desarrolladores profesionales según la encuesta de Stack Overflow, vs Visual Studio / IntelliJ ~28%). Código abierto y extensible desde 2015 (Microsoft); repo de GitHub con 150k estrellas. No confundir con Visual Studio (concepto distinto). Existe versión web en vscode.dev.
2. **Interfaz**: explorador de archivos, búsqueda, control de código (Git integrado), depuración, extensiones y testing; panel inferior con terminal, consola de depuración, salida y problemas; áreas reubicables.
3. **Ejecución de código**: ejemplos mínimos en Python y JavaScript lanzados desde el editor.
4. **Extensiones como rasgo definitorio**: sin la extensión Python no hay soporte; menciona GitHub Copilot (IA para programar), packs de iconos, temas, clientes REST, visores de bases de datos, incluso mascotas.
5. **Depuración**: breakpoints, ejecución paso a paso e inspección de valores.
6. **Paleta de comandos**: presentada como EL atajo a aprender primero — acceso a casi todo (crear ficheros, cambiar tema, acciones Git).
7. **Configuración**: settings por proyecto y por usuario, editable también como JSON.
8. **Cierre honesto**: VS Code no es el único editor — para móvil él usa Xcode y Android Studio; elegir según el stack.
